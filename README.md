# ⚽ KS Scheduler

Sistema para organização de partidas de futebol amador.

## Objetivo
Facilitar a criação e gestão de peladas, centralizando confirmação de presença, lista de espera e controle de pagamento.

## Perfis
- Organizador
- Jogador
- Dono da quadra
- Administrador

## Funcionalidades do MVP
- autenticação
- criação de partida
- visualização da próxima partida
- confirmação de presença
- lista de espera
- regras básicas de cobrança
- acompanhamento de pagamento
- compartilhamento via link/WhatsApp

## Stack
- .NET

- Blazor

- SQL Server
